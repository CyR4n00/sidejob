# Content Alchemist - 資産構築RPG

**「ゲーム感覚で継続できる、自動化コンテンツ生成ツール」**へようこそ！

アフィリエイトやSNSでの発信活動は「毎日の継続」が最も難しく、多くの人が挫折してしまいます。
この『Content Alchemist』は、あなたが**錬金術師**となり、AI（ChatGPT / Gemini）の力を借りてコンテンツを錬成し、実際の成果（閲覧数など）でレベルアップしていく新感覚のツールです。

難しい環境構築は一切不要。このファイルをダブルクリックするだけで、今日からあなたの「資産構築クエスト」が始まります。

---

## 🚀 はじめ方（起動方法）

特別なソフトウェアやサーバーは必要ありません。

1. ダウンロードしたフォルダの中にある **`index.html`** というファイルをダブルクリックしてください。
2. お使いのブラウザ（Google Chrome, Edge, Safariなど）が開き、アプリが起動します。

※もしダブルクリックでブラウザが開かない場合は、`index.html` をブラウザの画面上にドラッグ＆ドロップしてください。

## 🎮 遊び方（ツールの使い方）

### 1. クエストを受注する（クエストボード）
毎日、AIから「今日書くべきテーマ」がお題（クエスト）として提示されます。
「何を書けばいいかわからない…」という悩みをなくし、迷わず作業をスタートできます。

### 2. コンテンツを錬成する（錬成所）
ターゲット層や文章のトーン（親しみやすい、専門的など）を選び、「錬成開始」ボタンを押します。
AIが自動的に、高品質なブログ記事の構成やX(Twitter)のポストを作成してくれます。生成された文章をコピーして、ご自身のSNSやブログに投稿しましょう。

### 3. ギルドに報告して経験値(EXP)を稼ぐ（成果報告ギルド）
ここが一番の醍醐味です！
実際に投稿した記事やポストの**「閲覧数（インプレッション）」**や**「クリック数」**をアプリに入力してください。
現実世界のあなたの努力がそのまま「経験値」に変換され、クリエイターレベルが上がっていきます。目指せ、コンテンツ王！

## 🔑 AI APIキーの設定方法

このツールで実際にAIに文章を作ってもらうには、「APIキー」という専用のパスワードのようなものを設定する必要があります。
（※設定しなくても「モック（お試し）モード」で画面の動きを確認することは可能です）

本ツールは現在、**OpenAI (ChatGPT)** と **Google Gemini** の2つに対応しています。お好きな方を選んで設定してください。

### A. Google Gemini を使う場合（おすすめ・無料で始めやすい）
1. [Google AI Studio](https://aistudio.google.com/app/apikey) にGoogleアカウントでログインします。
2. 画面の指示に従い、「Create API Key」ボタンを押してキーを作成します。
3. 表示された文字列（AIza...から始まる長い文字列）をコピーします。
4. 本アプリの「設定」タブを開き、AIモデルを「Google Gemini」に変更します。
5. コピーしたキーを貼り付けて「保存する」を押します。

### B. OpenAI (ChatGPT) を使う場合（高精度）
1. [OpenAI API Platform](https://platform.openai.com/api-keys) にアクセスし、アカウントを作成・ログインします。
2. 「Create new secret key」をクリックして新しいキーを作成します。
3. 表示された文字列（sk-...から始まる文字列）をコピーします。
4. 本アプリの「設定」タブを開き、AIモデルを「OpenAI (ChatGPT)」に変更します。
5. コピーしたキーを貼り付けて「保存する」を押します。
※OpenAIのAPIを利用するには、クレジットカードの登録と少額のチャージ（通常5ドル〜）が必要です。
